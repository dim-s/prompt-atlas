Правило: когда изменение делает факт о модели иным — переименование, новая модель, снятый/добавленный параметр — сначала сформулируй затронутое УТВЕРЖДЕНИЕ как класс (старое имя; «кто ещё тюнит sampling»; ступень effort-ладдера) и найди его grep-ом по ВСЕМУ репозиторию, а не по местам, которые помнишь или указал ревьюер. Гейт готовности в плане записывай КОМАНДОЙ по голому токену — имени модели или поля, без окружающей фразы: `git grep -n -i '<токен>' -- . ':!CHANGELOG.md'`, с числом хитов и разбором КАЖДОГО (файл:строка → правлено / история, почему). Перечень шаблонов устаревших фраз как определение готовности — та же правка по известным местам: он ловит только фразы, которые ты уже знаешь (v2.1.0: 13 шаблонов, а по токену `Argon` — 79 хитов в 10 файлах). К grep по свойству добавь grep по КВАНТОРАМ над семейством новой модели (`every|all|only|other|rest|first|any` рядом с именем вендора/семейства или `current`): фраза «every other current Claude» не содержит ни имени новой модели, ни токена свойства, и grep по свойствам её не видит. То же — до того, как пишешь СВОЁ утверждение с квантором («first documented X knob», «only Y supports», «inverts Z»): сперва grep этого свойства по файлу вендора и репо, иначе новая строка ложна против уже записанного. Правь каждое живое вхождение в том же изменении, не выноси в follow-up: CONTRIBUTING §«How to update an existing cell» требует чинить ячейку, ставшую неверной. Вхождение пропускаешь — сперва открой саму строку и назови, почему она не того класса; обоснование по памяти о файле не годится. Упоминания в истории прошлых версий (CHANGELOG, записи «когда X стал доступен», титулы первоисточников, словари сигнальных токенов) законны и не правятся.
Почему: точечный поиск структурно не покрывает дерево — в двух сессиях по два-три раунда гейта подряд находилось новое место того же класса, потому что правили перечень мест, а не класс. Сработало на v1.8.0 р.3: grep по классу (sampling + `none` в effort-ладдере) и правило вместо перечня → финальный гейт чистый. v1.9.0 р.1: grep по свойствам исполнитель сделал сам, но кванторные обобщения («every other current», «first documented») мимо него — отсюда шаг с кванторами. v2.1.0: урок прочитан на старте, но «класс» исполнитель понял как перечень фраз — поэтому форма гейта задана командой, а не словом. Различение «живое/история» нужно, чтобы grep по репо не стал чисткой законной истории.
